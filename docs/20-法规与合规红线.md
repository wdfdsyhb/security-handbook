# 20 法规与合规红线

> 挖洞先懂法。这一章是每次提交报告前的自检清单，也是安全从业者的职业底线。

## 《网络产品安全漏洞管理规定》（2021-09-01 施行，最直接相关）

白帽核心义务（第四条）：
- **不得恶意利用漏洞**
- **不得夸大危害**
- **不得出售、发布漏洞信息牟利**

关键条款：

| 条款 | 内容 | 对白帽的意义 |
|------|------|--------------|
| 第七条 | 产品提供者发现漏洞 **2 日内**报送工信部威胁和漏洞信息共享平台 | 对厂商，不是对白帽 |
| 第九条 | 修补措施发布前**不得提前公开**漏洞细节；不得夸大危害；**不得提供利用程序/工具**；发布须同步给出修补或防范措施 | 写 writeup/发 PoC 的红线 |
| 第九条 | **国家重大活动期间未经公安同意不得发布漏洞信息** | 多数人不知道的实操红线（HW 期间尤其注意） |
| 第十条 | 漏洞收集平台须向工信部备案；**不得将未公开漏洞提供给境外组织或个人**（除产品提供者之外） | 给 HackerOne/海外平台交国内未公开漏洞=违法 |
| 第十四、十五条 | 违规收集发布、利用漏洞从事危害活动由公安部追责；构成犯罪追究刑事责任 | 刑法衔接 |

## 相关法律框架（要点速览）

- **《网络安全法》**：网络运营者安全保护义务；等级保护制度；关键信息基础设施。非法侵入他人网络、干扰功能、窃取数据=禁止（27 条）
- **《数据安全法》**：数据分类分级；重要数据出境评估。采集泄露数据=违法
- **《个人信息保护法》**：处理个人信息需同意；敏感个人信息（生物识别/宗教/医疗/金融/行踪）单独同意。**漏洞验证时拿到个人信息=立即停止+不得留存**（最小必要原则）
- **《刑法》285 条**：非法侵入计算机信息系统罪；**非法获取计算机信息系统数据罪**（越权拿数据踩这条）；提供侵入工具罪（**卖 PoC/武器化工具踩这条**）
- **《刑法》286 条**：破坏计算机信息系统罪（删库/flushall/篡改数据踩这条）
- **等保 2.0**：企业侧合规基线（了解即可，面试谈防守时用）

## 行为红线清单（每单开测前过一遍）

1. 只测授权范围内资产——scope 逐条核对，**出 scope 立即停**
2. 不碰真实用户数据——需要验证危害用**自己的测试账号**构造数据；不小心拉到他人数据立即停止并说明
3. 不可逆操作禁止——不上 flushall 类 exp、不删数据、不篡改生产库
4. 不做拒绝服务测试（除非平台明确允许）
5. 不社工员工（除非平台明确允许）
6. 漏洞细节先报平台，披露窗口期内不公开
7. 不卖给境外、不发给境外、不发海外平台（未公开漏洞）
8. 重大活动期间（HW/两会/重大会议）收敛动作
9. 报告不夸大——"可导致服务器沦陷"要能证明才写
10. 不出售漏洞给黑产/催收/竞对

## 溯源自保

- 测试用专属标识：平台提供的测试 header、专属测试账号、可解释的 IP（家宽优于云服务器——云 IP 被 SCDN 记录后难自证）
- 全程留痕：自己的操作日志、burp 记录、时间线——被误判攻击时能自证
- 收到厂商/公安问询：如实说明测试授权范围，提供平台工单
