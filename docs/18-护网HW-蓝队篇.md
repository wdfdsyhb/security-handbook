# 18 护网 HW · 蓝队篇

> 学生打 HW 从蓝队监控位切入最现实。蓝队拿分三件事：监测发现、应急处置、配合取证。

## 防守四阶段

**备战**（减攻击面）：资产梳理、暴露面收敛、弱口令清理、高危漏洞修复
**临战**（演练）：监控值守排班、上报流程演练
**决战**（监测响应）：7×24 值守、告警分析、应急处置
**总结**：复盘、加固闭环

### 备战自查清单（攻击面收敛）

- 资产表核对：归属域/系统、IP（主备/浮动）、开放端口、Web URL、可访问位置及授权、防护手段（ACL/IPS/WAF）
- 采集方法：管理员原始表+SOC 导出 → 网段存活探测 → 全端口服务探测(1-65535) → **边界设备日志反查未登记资产** → 无归属资产关停下线
- 互联网暴露面收敛；非必需端口严格限制
- 弱口令清理：字典=账号库+口令库（默认口令+行业口令+厂商口令+人名拼音/手机号）；**扫描期临时关闭账号锁定策略，扫完立刻恢复**（这是红队的爆破窗口）
- 扫描纪律：重要资产夜间扫、邮件留痕授权、未扫过设备逐 IP 扫、误报五场景（OS 指纹错/Oracle 补丁号取不到/openssh 旧文件残留/定制版本/未启用受影响模块）、**防火墙代答制造假端口**（0 进度=不通，无漏洞=被阻断）
- 安全域与策略：重要区域对互联网"原则上不允许"；检查策略合规（目的 IP/端口范围过大）、策略有效（扫描端口与开放端口一致）、多外网出口是攻击路径图

## 检测三角（理解体系才知道盲区）

1. **告警依赖设备规则启用**——未启用的场景规则=无告警；日志未接入的设备=盲区；私网 IP 未导入资产不产生态势事件（"资产+事件"双条件）
2. **二段式判定**：告警日志 + HTTP/会话日志关联 = 确认失陷。常见 payload 特征：`whoami`、`wget …sh|sh`、`echo 123 | bash -i>& /dev/tcp`、`cmd.exe /c certutil -urlcache`
3. **统计特征**：源 IP 聚合（多类型攻击=扫描，随后骤降=手工渗透开始）、频率异常、响应码

### 各类攻击的判定特征（公式化）

| 攻击 | 判定 |
|------|------|
| Webshell 入侵 | Webshell URL + HTTP 主动访问 200 OK（**非 200 漏报**） |
| 挖矿 | 连接矿池（session 含 `"method":"mining.subscribe"`）+ DNS 请求链 |
| 永恒之蓝 | Ms17-010 漏洞利用 + doublepulsar 后门连接（会话下行包数>20 且上行流量>4k） |
| 扫描 | 源 IP 固定 + 访问频率异常 + 协议摘要含验证 payload |
| 工具爆破 | 错误认证时间隔小 + 源 IP 固定 |
| 失陷资产 | 连接方向内→外 且 攻击阶段 stage≥5 |

## 安全设备产品线职责（绿盟系为例，乙方面试常考）

| 产品 | 职责 | 关键点 |
|------|------|--------|
| NTI | 威胁情报中心 | IOC/基础情报/漏洞情报；暴露面核查（高危主机=开 SSH/Telnet/RDP/SMB/数据库端口） |
| TSA/态势感知 | 态势呈现 | 前提="资产+事件"；GROK 自定义解析第三方日志 |
| IPS/NIPS | 特征+统计双机制 | 策略按优先级遍历；归并 3600 秒；旁路 NIDS 只检测 |
| WAF | Web 防护 | 误报判断三步：匹配关键词→规则描述→HTTP 原文；调优先资产登记再逐步开阻断 |
| ESPC | 统一管理平台 | 设备管理/日志报表/告警；危险度求和 M=3A+2B+C≥K 触发 |
| TAC | 威胁分析沙箱 | 四引擎顺序：信誉→病毒→静态→动态；白名单优先 |
| UTS/TAM | 全流量 | 可 pcap 取证回溯；复合事件（蠕虫/DNS 隐蔽信道/Webshell）；失陷判定 stage≥5 |

## 应急响应三要素法

- **时间**：攻击发现时间 / 后门文件时间 / 异常时间段——对齐 Web/系统/安全设备日志
- **地点**：恶意文件首次出现目录 → 反查上传点或代码执行点
- **事件**：应用后台登录日志 + 安全设备告警 + FTP/SSH/远程桌面日志 + web 运行账户

排查优先目录：`/var/tmp`、`C:\Users\*\Downloads`、tomcat `conf/tomcat-users.xml`、WebLogic `_WL_internal`、上传目录、中间件根目录。

工具链：Tcpview（外联）、AutoRuns（启动项）、D 盾/findwebshell（查马）、LogParser（`select * from security.evtx where EventID=5080`）、goaccess 出 html 报告。取证对象：木马样本+全套日志+残留文件+抓包；处置=断网隔离→根除→恢复。

## 事件分级与闭环

分级：4 级扫描、3 级爆破/钓鱼、2 级高危漏洞利用/木马、**1 级内网扫描/内网爆破/内网高危利用（最重）**。

闭环六阶段：准备→发现→报告→分析→处理→总结；处理=遏制（封 IP/URL）→根除（修漏洞）→恢复（清马重置账号）。

**上报拿分要点**：上报源 IP+流量分析+样本才计分，只截设备告警图不计分；1 小时内上报且取证完整可免扣分。

## 蓝队反制（面试必考）

- 蜜罐：伪造脆弱服务收集攻击者指纹与 0day（注意越权使用边界）
- 反渗透：攻击 IP 反查身份（测绘/社工）、溯源取证
- 反钓鱼：邮件网关+员工上报（+20 分/起）
- 溯源常见链路：C2 IP→测绘定位→IDC 备案/whois→关联历史活动→攻击队画像
