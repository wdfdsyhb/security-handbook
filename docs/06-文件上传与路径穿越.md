# 06 文件上传与路径穿越

## 上传点定位

**任何存在上传操作处都可能中招**，概率排序：网站后台 > 用户中心头像 > 论坛图片 > 附件 > 数据备份恢复位。远程更新功能（可指定更新服务器）是偷梁换柱的非常规入口。

## 黑盒方法论：先看响应差异

**先收 OS/语言/服务器/版本 → 对比正常与非法上传的响应差异，推测后台判断逻辑 → 再构造针对性请求**。不要盲 fuzz：

- "刚选定文件就提示不允许" = 前台 JS 验证 → Burp 改包直传
- 提交后报"非法文件" = 后端后缀校验 → 换后缀/解析漏洞/截断
- 上传成功但访问 404 = 改了文件名 → 找回真实路径
- 上传成功访问 403 = 目录禁执行 → 传 .htaccess/.user.ini 或转打 XSS

## 四层利用决策树

1. **敏感后缀直传**：php/jsp/aspx —— 被拦进下一层
2. **后端校验**：换可解析后缀（php4/php5/phtml/jspx/ashx）→ 解析漏洞 → %00 截断（老版本 PHP<5.3.4）
3. **解析漏洞**：Apache（`1.php.xxx`、`.htaccess`）、IIS（`;` 截断、目录解析）、Nginx（`/1.jpg/1.php` cgi.fix_pathinfo）、PHP-CGI
4. **目录不执行**：传 html 打存储 XSS；传 `.htaccess`/`.user.ini` 改解析配置

## 八条绕过矩阵（checklist）

a. 禁 JS/抓包重放绕前端校验
b. 改 Content-Type（`image/jpeg` 配 PHP 后缀）
c. 构造文件头（`GIF89a` + 图片马）绕 `mime_content_type`/Fileinfo/getimagesize
d. 用其他解析标签形式绕 `<?php` 检测（`<?=`、`<script language="php">`）
e. %00 截断或 fuzz 后缀黑名单边界（php3/phps/phtm）
f. Windows NTFS ADS 特性（`1.php::$DATA`）
g. Apache/IIS/Nginx/PHP-CGI 解析漏洞
h. 传 `.htaccess`（`AddType application/x-httpd-php .jpg`）或 `.user.ini`（`auto_prepend_file`）

**正则判断文件最易出问题**——防御用正则，攻击就 fuzz 正则边界。

## Webshell 工具与免杀

| 工具 | 特征 |
|------|------|
| 中国蚁剑 / 菜刀 | 流量特征明显，易被 WAF 识别 |
| 冰蝎（Behinder） | **流量动态加密**，区别于菜刀/蚁剑 |
| 哥斯拉（Godzilla） | 加密+变形，目前主流 |

一句话木马检测特征：`eval($_POST[...])`。绕检测：str_replace 拼接函数名、变量引用、非 200 响应码回显。

## 路径穿越（LFI/任意文件读取）

```
../、..\、%2e%2e%2f、%252e%252e%252f（双重编码）、%c0%ae（超长UTF-8）、..././、....//、%00 截断
```

- Nginx 与 Tomcat 对 `/..;/` 解析差异（Nginx 当目录，Tomcat 当 `/../`）——反代环境必测
- 升级链：LFI → 读 session/日志 → 日志投毒 → RCE
- PHP 危险函数 sink：`include/require`（文件包含）、`system/exec/shell_exec/passthru/pcntl_exec`（命令执行）、`eval/call_user_func/create_function/array_map/assert`（代码执行）

## 防御判定标准（加固时对照）

白名单过滤、文件重命名（时间戳+随机数，不可暴力遍历）、非上传目录不给写权限、**上传目录禁执行**、二次渲染（按上传图片重新生成新图并删原图，图片马失效）、老版 iis/apache/nginx 打补丁。
