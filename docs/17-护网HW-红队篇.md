# 17 护网 HW · 红队篇

## 计分规则（先懂规则再打法）

- 攻击方以**获取权限/数据**得分，路径上资产均得分；**提交漏洞不得分**——别浪费时间证明漏洞存在，直接打权限链。
- 靶标提前 3 周通知；不限攻击路径。
- 防守初始 5000 分，攻击得分手感：终端权限 10/台、Webshell 20/个、邮箱/VPN/FTP 账密 20-60/个、域控管理员 300（累计上限 3000）。
- 防守加分项（=红队注意别送取证）：发现木马 50、处置 Webshell 50——**防守上报需样本+流量+日志完整证据链**；攻击报 1 小时内上报且取证可免扣分。

## 攻击链总览

```
侦察 → 武器化 → 载荷传输 → 弱点利用 → 装后门 → C2 → 横向
```

## 降噪与规避（对抗检测三角）

蓝队检测体系三大支柱（详见 18 章），对应红队三条降噪主线：

1. **告警依赖设备规则启用** → 未启用的场景规则=无告警；未接日志源的哑设备=监测盲区；私有协议=不识别
2. **"攻击动作+外连行为"二段式判定** → Webshell 访问保持异常响应码（非 200 漏报）；C2 走新鲜域名/CDN（威胁情报无劣迹记录）；控制端域名不进黑名单
3. **统计特征**（源 IP/频率/响应码）→ IPS 日志归并默认 3600 秒——**慢速多源低频**稀释计数；出网 IP 全国轮换规避封禁；把高危利用做成"分布式低频"降级为扫描级事件

**TAC 沙箱检测链顺序**：自定义白→黑→文件白→信誉→AV→静态→动态，命中白名单不再检。规避：PE 改图片后缀（哈希信誉查不到）、新型样本（信誉库空）、无文件/不落盘载荷（钓鱼宏直接内存执行只走静态环节）。

## 免杀要点

- 落盘规避：shell 落随机名/加密目录；复用现有 web 进程用户执行（无新增文件+无新账户）
- 无文件化：powershell 内存执行；反射加载
- 静态特征：shellcode 分离（loader+加密载荷）、加壳（注意沙箱会动态脱）、签名伪造
- 行为特征：sleep 混淆、正常进程注入（explorer.exe）、流量伪装（域前置/CDN）

## 出题与训练视角

- 攻击队默认手法顺序：旁站攻击 → 暴力破解 → Web 渗透 → 提权
- 蓝队拿分逻辑反推红队陷阱：**只截设备告警图不计分**——红队别在告警明显的路径上浪费动作；取证链不完整的上报不生效
- 参加挑战赛（SQL/XSS/WAF 挑战赛）测 WAF 规则缺陷并攒经验
