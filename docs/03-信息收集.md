# 03 信息收集

> 信息收集决定攻击面。后台多挂在二三级域名而非目录下——目录探测永远扫不到，只有子域名爆破能找到。

## 子域名收集

### 多通道并用（单通道必漏）

| 通道 | 工具/方法 | 备注 |
|------|-----------|------|
| DNS 区域传送 | `dig @ns.xxx.cn axfr xxx.cn` / `nmap --script dns-zone-transfer -p 53` | 存在即拿全量子域，测试是否配置错误 |
| SSL 证书 | crt.sh、censys.io | **首选**——挖了两年的老目标仍能挖出未收集的二级域名 |
| 枚举爆破 | subDomainsBrute、layer、subfinder | 耗资源，泛解析下需比对法排噪 |
| 微步在线 | 在线查询 | 能查出三四级域名 |
| 备案号关联 | nosec.org 等备案查询 | 同备案号 = 同公司其他域名 |
| APP 抓包 | 提取全部链接/IP | 移动端 API 常不在 web 资产表 |
| crossdomain.xml | `http://target/crossdomain.xml` | 常藏不显眼的内部网址 |
| C 段搜索 | `site:10.10.10.*` 类语法 | 内网暴露面 |
| Github 精准搜 | 针对某域名搜代码 | 比大范围枚举精准 |

### 域名爆破四技巧（破泛解析与深挖）

1. **基准 A 记录比对**：先解析一个随机不存在域（如 `chorashuai.xx.com`）取基准 IP；枚举结果中 IP 与基准不同者才是真实在用的域名——泛解析下这是唯一的排噪方法。
2. **递归爆破**：爆出 `a.xx.com` 后把它当新目标继续爆（`house.xx.com` → `db.house.xx.com` → `esf.db.house.xx.com`），可挖到 6 级深度。
3. **字典补 4 位**：别只做 1-3 位，4 位也要跑（5 位数概率太低可放弃）。
4. **占位符定向爆破**：大厂命名有规律（`mxxx.bb.com`、`adxxx.bb.com`、`bb-o2o.bb.com`），用 `m{fuzz}.bb.com` 式模式在指定位置填充，专挖隐藏域名。

注意：持续爆破会打满本机路由（DNS 请求量问题，限速无效），工具必须可暂停。

## crt.sh → Github 链式打法（实战案例）

1. crt.sh 挖出二级域名
2. Github 搜该域名 → 找到三级域名的接口代码
3. 按源码拼 GET 请求 → 报错回显参数名 → 按代码要求构造 JSON 头
4. 命中反序列化（如 fastjson `{"@type":"com.sun.rowset.JdbcRowSetImpl",...}`）→ 进生产内网

Github 搜索技巧：**登录态搜索结果更多**；搜建站人员/外包厂商遗留的敏感文件；`site:github.com intext:公司名 password`。

## IP 段收集

1. CNNIC IPwhois 查单个 IP → 得**网络名称**（如 `Netease-Network`）
2. 按网络名称反查该组织全部 IP 段（不支持模糊查询；大公司有多个网络名称，直接用公司名查也有效）
3. masscan 全端口 + nmap 识别（`-sV -sT -Pn --version-all --open`）
4. **masscan 防 WAF 误判**：遇 WAF 会返回海量假开放端口——实时监视 found 数，超阈值（如 80）即 kill 跳过该 IP；masscan 的 `-oX/-oJ` 捕获不到打印内容，须解析 stdout 正则提取
5. IP 段分核心段/边缘段/云服段——**边缘段测试机是最佳突破口**（不关 debug、弱口令、不入安防套餐）

## 字典工程化

- **四分类字典**：从 1000+ 开源 web 源码用正则提取**目录名 / 可执行脚本名 / 参数名 / JS 文件名**四类字典
- **入库按命中次数排序**（dict_count 降序），越用越准
- 子域名字典源：rapid7 fdns/rnds 开放数据
- **403/404 站点更易出洞**：轻量扫描器（BBscan 类）先扫目录（如 `/adver/landing.php`），再参数爆破（`mac=1`）→ SQL 注入。重型扫描器（AWVS）会被安防套餐封 IP，慎用

## Github 泄露挖掘

五类高价值目标：账号密码（公司邮箱/VPN）、核心算法、**API KEY（可直接打接口）**、服务器 key/配置、源码（可审出 0day）。

- 工具：gitrob（遍历组织成员仓库匹配敏感文件名）、GitPrey（企业关键词检索）、weakfilescan（动态收集生成字典）、GitMiner、GitHarvester
- **全部做成定时任务自动化跑**，手动搜索必漏
- 拿到源码后的三步利用链：审源码找注入/上传 → 拿敏感配置直连 → 摸业务流程降低后续成本
- 按外包厂商的代码指纹反查其客户的泄露（外包代码多处复用）
- 历史遗留：PHP 站转 ASPX 后旧 PHP 文件不再被解析，源码可直接看

## 目录与备份文件

- 备份文件命名规律：`www_|www|backup_|backup` + 域名变体 + `.zip|.rar|.7z|.gz|.sql|.mdb|.bak`
- 无 index 主页试列全目录；**上传身份证处删除 URL 中的图片文件名/后缀试目录遍历**
- Tomcat 组件敏感目录：conf 最敏感（xml/properties 存用户、数据库配置）
- robots.txt、django debug 模式泄露 URL 清单

## 社工与第三方线

- theharvester 收邮箱用户名 → 拿用户名/web author 去 Github 搜建站遗留
- 网盘搜索、QQ 群文件、招聘信息（技术栈+人员名）
- APP 证书锁定绕过：iOS 越狱用 SSL Pining Disable，安卓用 DroidSmartUnpinning/Xposed 模块
