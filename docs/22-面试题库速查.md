# 22 面试题库速查

> 护网/安全岗高频题与答案要点。考察逻辑：①背流程题是定级门槛（打点流程/应急六步答顺就过初筛）②红蓝对照出题（webshell 红队问免杀蓝队问检测）③高频洞+端口表是开口就要报的硬通货。开场必问护网经历，没有一般定初级。

## 红队高频

**外网打点流程**：靶标确认→信息收集→漏洞探测→利用→权限获取，信息收集最关键。

**FOFA 技巧**：title/body/host 组合挖后台、子域、C 段、框架特征、列目录漏洞。

**识别 CDN**：ping 回显、nslookup 解析、超级 ping 看多地区 IP 是否一致。

**判断 Win/Linux**：大小写敏感差异 + TTL 值（Windows>100、Linux<100）。

**Windows 隐藏用户**：`net user test$ /add` + 加入 administrators 组。

**Windows 提权路径**：内核溢出、数据库提权、错误配置、中间件漏洞、第三方软件。
**Linux 提权路径**：内核漏洞、SUID、环境变量劫持、sudoer 配置。

**正反 shell**：正向=攻击者连目标（目标有公网）；反向=目标主动回连（目标在内网）。

**PHP 危险函数**：命令执行 system/exec/shell_exec/passthru/pcntl_exec；代码执行 eval/call_user_func/create_function/array_map/assert/proc_open/popen/putenv。

**disable_functions 绕过**（经典笔试）：pcntl_exec、putenv+LD_PRELOAD、imap_open、FastCGI、ImageMagick（CVE-2016-3714）。

**Webshell 工具区别**：冰蝎=流量动态加密；菜刀/蚁剑特征明显。

**SQL 注入分类**：按注入点（数字/字符/搜索）、提交方式（GET/POST/Cookie/HTTP头）、结果（报错/布尔盲注/时间盲注/联合/堆叠/宽字节/二次注入/万能密码）。
**SQL 注入预防**：预编译、PDO、正则过滤。

**序列化 vs 反序列化**：对象→字节序列 / 字节序列→对象；PHP unserialize、Java readObject。

**内网渗透思路**：代理穿透、权限维持、信息收集、口令爆破、凭据窃取、横纵渗透、拿域控。

## 中间件漏洞（报菜名题）

| 中间件 | 漏洞 |
|--------|------|
| IIS | PUT 上传、解析漏洞（`;`、目录 `/xx.asp/xx.jpg`）、短文件名枚举 |
| Apache | 解析漏洞（`1.php.xxx`）、SSI、路径穿越 |
| Nginx | 解析漏洞（cgi.fix_pathinfo）、CRLF 注入、目录穿越（alias 配置错误） |
| Tomcat | PUT 上传（CVE-2017-12615）、manager 弱口令 war 部署、examples 示例页 |
| WebLogic | T3 反序列化、SSRF（CVE-2014-4210）、弱口令 |
| JBoss | 反序列化、JMX 控制台未授权 |
| Shiro | rememberMe 反序列化（Shiro-550 硬编码 key / Shiro-721 padding oracle） |
| Log4j2 | JNDI 注入（Log4Shell）：日志处理触发 `${jndi:ldap://}` 任意代码执行 |
| ThinkPHP | 5.x RCE（路由正则缺陷） |
| Spring | Actuator 未授权、Spring4Shell |

## 蓝队高频

**应急响应流程**：准备→检测→抑制→根除→恢复→报告（六步）。

**webshell 检测工具**：D 盾、河马、findwebshell、CloudWalker、静态+流量双检。

**威胁情报平台**：微步在线、奇安信 TI、绿盟 NTI、VirusTotal、AbuseIPDB。

**蓝队反制手段**：蜜罐（收集攻击者指纹与 0day）、反渗透（IP 反查身份）、反钓鱼（邮件上报）。

**判定失陷**：告警日志 + 外连行为关联（详见 18 章判定公式表）。

**挖矿判定**：连接矿池（`"method":"mining.subscribe"`）+ DNS 请求链。

**应急排查位置**：/var/tmp、用户 Downloads、tomcat-users.xml、_WL_internal、上传目录；工具 Tcpview/AutoRuns/D 盾/LogParser。

## 概念辨析题

- **水坑 vs 鱼叉**：水坑=先攻目标常访问的网站等其上钩；鱼叉=定向邮件附件投递。
- **APT**：高级持续性威胁——定制化+长期潜伏+多阶段。
- **同源策略**：协议+域名+端口三者一致；CORS 是受控放宽。
- ** honeyport / 蜜罐**：诱饵服务，区分低交互（端口banner）与高交互（完整系统）。
