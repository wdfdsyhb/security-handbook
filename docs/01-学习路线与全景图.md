## OWASP Top10 2021（当 checklist 用）

按 A01-A10，每类记「风险+攻击范例+预防」：

1. **A01 失效的访问控制**（发生率第一，34 个 CWE）— 改 URL 参数/强制浏览/IDOR/API 未对 POST·PUT·DELETE 鉴权/JWT 重放/CORS 错配。测试点：横向改 `acct` 参数、纵向访问 `/admin_getappInfo`。
2. **A02 加密机制失效** — 明文传输、弱哈希、证书校验缺失。
3. **A03 注入** — SQL/NoSQL/OS 命令/LDAP/EL/OGNL。**对一切参数、标题、URL、cookie、JSON、SOAP、XML 做测试**；源码审计是检测注入的最佳方法。
4. **A04 不安全设计** — 业务逻辑缺陷的总类，无法靠扫描器发现。
5. **A05 安全配置错误** — 默认口令、目录列表、错误堆栈回显、示例应用未删。四个攻击范例本身就是扫测项。
6. **A06 自带缺陷和过时的组件** — Struts2 CVE-2017-5638 类；工具：Dependency-Check、retire.js。
7. **A07 身份识别和身份验证错误** — 撞库/爆破/弱密码/会话 ID 进 URL/登出不轮换。
8. **A08 软件和数据完整性故障** — 反序列化、CI/CD 供应链。
9. **A09 日志记录和监控失效** — 攻击者视角：防守无日志=动作可最大化。
10. **A10 SSRF** — `file://` 读文件、`http://localhost:28017`、云元数据 `169.254.169.254`，三个即测 payload。

方法论要点：用**事件发生率**而非频率统计，关注**根本原因**而非症状。

## 学习路径（零基础 → 实战）

1. **Web 基础**：HTTP 协议、浏览器安全模型、HTML/JS 能读懂、《OWASP 渗透测试指南》读两遍（第一遍粗读结构、第二遍细读）。
2. **按漏洞类型逐类击破**：本书第三部分每章 = 一个洞型的完整方法论，配 JSRC 安全小课堂式的案例文。
3. **靶场**：OWASP 虚拟机、Pikachu、Vulhub；预算够买二手路由器做固件分析。
4. **平台实战**：从漏洞盒子/补天公益 SRC 入手（收录广、难度低、edu 资产多）→ 读平台收录标准再挖（不收反射型 XSS 的平台别浪费时间）。
5. **工具分水岭**：Burp Scanner 自动扫描是能力的复制；能写 Burp 插件/自写扫描器才是分水岭。

## 定级公式与严重性判断

- **漏洞定级 = 敏感数据有无 + 漏洞利用成本 + 危害面积**（2000 块的展示站有 SQL 注入最高定中低危）。
- **严重级判定 = 业务影响大 × 范围广**。技术难度高但业务影响小（如测试库的隐蔽 SQL 注入）不算严重。
- 中危参考：任意密码重置、越权、SQL 注入、绕过登录；高危参考：命令执行、文件上传、域控。
- CNVD 门槛：通用型需中危及以上（CVSS2.0≥4.0）。

## 法规底线（先记住再动手）

- 只测授权范围内的资产——SRC 平台读清 scope，越界 = 非法测试。
- 《网络产品安全漏洞管理规定》：不恶意利用、不夸大危害、不出售发布漏洞牟利；**未公开漏洞不得提供给境外组织或个人**；国家重大活动期间未经公安同意不得发布漏洞信息。
- 详细红线见第 20 章。
