# 13 内网渗透

> 进入内网的标志：拿到边界主机 shell/凭据。内网最薄弱的环节是弱口令与信任关系。

## 打点后第一步：信息收集

### 人员/机器两分法

- **人员**：有 domain 用 ldap 收集、翻 OA 系统、进员工邮箱爬通讯录
- **机器**：`dsquery` 命令取；工作组用 nbtscan 扫机器名（机器名常含员工名或用途）；`net group` 找服务器组（邮件/WEB）再扫该段常见端口

### 主机侦察

- nmap 探内网 IP 段端口服务；IIS PUT Scanner；数据库/FTP 批量爆弱口令
- ARP 欺骗动静太大不建议（蓝队/网管立刻察觉；nmap 带 --script 同样易触发警觉）
- 翻文件：`.ssh/`、`.bash_history`、环境变量、浏览器保存密码、共享目录

## 域环境

- 摸域：看域管理员有谁、最后登录时间、home dir 里的脚本
- 找到能通内外的**边界服务器**作为立足点（跳板）
- 横向：口令复用（批量 SSH 同口令）、hashdump + 哈希传递（PTT/PTH）、MS17-010 打 SMB
- 权限提升：Windows 内核溢出（ms16-032 类）、数据库提权、错误配置（服务路径含空格未加引号）、AlwaysInstallElevated、第三方软件
- 攻击域控 = 护网最高扣分项（300 分/管理员），也是实战的最有价值目标

## 代理与隧道

- 部署代理跳板：frp/nps/socks5 链式代理，让本机 Burp 能打内网 web
- 文件下载：certutil（Windows）、wget/curl、powershell IEX——全流量设备对常见下载命令有特征（见 18 章蓝队判定公式）

## 四大经典问题

1. 防火墙穿透（隧道/协议复用）
2. 木马免杀（见 17 章红队）
3. 内网信息收集与目标定位（本章）
4. 文件下载

## 留痕规避（红队视角）

- 落盘是应急的抓点：shell 落随机名/加密目录、复用现有 web 进程用户执行命令（无新增文件+无新账户）
- 无文件化：powershell 内存执行、不落盘载荷
- 慢速低频：快扫触发 IPS 统计告警（见 18 章）
- C2 走新鲜域名/CDN：防守靠威胁情报 IP 画像秒级识别有历史劣迹的 IP

## 应急排查视角（蓝队反向清单——知道蓝队查什么才知道怎么藏，也知道自己怎么自检）

- 时间三对齐：攻击发现时间/后门文件时间/异常时间段 对齐 Web/系统/安全设备日志
- 攻击者常用落点（自检优先查）：`/var/tmp`、`C:\Users\*\Downloads`、tomcat `conf/tomcat-users.xml`、WebLogic `_WL_internal` war 目录、上传目录、中间件根目录
- 工具：Tcpview 查外联、AutoRuns 查启动项、D 盾/findwebshell 查马、LogParser、goaccess
- 取证对象：木马样本+全套日志+残留文件+抓包；处置=断网隔离

## 权限维持

- Windows：隐藏用户 `net user test$ /add` + administrators 组、注册表启动项、计划任务、服务
- Linux：crontab、SSH 公钥、SUID 后门、LD_PRELOAD
- Web 层：不死马（内存马）、隐藏 webshell（复用现有文件）
