# 09 业务逻辑与竞态

> 业务逻辑漏洞无法自动化，纯靠脑子和经验——竞争少，且国内 SRC 最看重业务安全。金融相关（支付/退款/折扣）是高价值目标。

## 密码找回五板斧

1. **4 位验证码爆破**：无次数限制 1 万次即破（6 位约 10 分钟）
2. **本地验证替换返回包**：先改自己密码存下正确返回包，再改他人密码时替换返回包
3. **改包中 userid**：该 ID 常在别处可获取（遍历/个人资料页）
4. **接收验证码的手机号参数改成自己的**：验证码发给自己，账号是别人的
5. **用生成验证码时的身份标识（cookie）替换**：验证码与账号不绑定

**核心缺陷模式**：验证码与用户身份不匹配校验缺失 + 流程分段处不回验。两个测试视角：
- 验证参考可控：后端把身份校验凭证直接返回前端；时间戳/用户 id 类凭证可猜解
- 校验用户身份放前端：直接改返回包的校验结果绕过

附加：绑定手机/邮箱处把绑定账户改为受害者，把别人账号绑到自己手机再重置；注册时前端返回"已存在"，改为"可注册"提交可覆盖他人账号。

## 短信验证码

必测项：
- **回显**：bp 抓包输入验证码，检查返回的 url/body/http 头是否回显验证码（明文或 md5）——成因是 debug 逻辑或前端验证
- **固定码**：案例里出现过 888888
- **不绑定用户**：只验证码有效不验证与身份的匹配
- 可复用（一个验证码用 N 次）、4 位且不过期（可爆破）、本地校验、验证码值编码后出现在数据包（顺带测短信内容可控）
- 健壮性：长度、随机性+有效次数、验证频率（短信轰炸=各平台验证码接口轮询）、二次验证

## 交易支付参数矩阵

**公式思维**：`个数 × 单价 - 优惠券 = 总额`，每个参与计算的值都可改。对金额、数量、单价、优惠逐项注入：**负数、0、小数、超大值**，能生成订单进支付页即有洞。

七个经典场景：

1. **负数数量抵消总价**：加负数数量商品平衡总额
2. **负负得正**：余额支付时数量改负数 → 总额为负 → 余额增加
3. **优惠券换商品**：用满 200 减 100 券再换成 101 元商品实付 1 元
4. **支付结果本地验证**：改返回包变已支付
5. **充值只判状态不核金额**：改订单金额（订单号不变）回支付页支付成功
6. **付款包改用户 ID**：注册一个 123456 简单密码账号，**对用户 ID 暴破**，用他人余额支付
7. **订单编辑**：订单生成后把 A 商品价格换成 B 商品价格；未支付订单不设自动取消时批量锁死库存；遍历地址 id 看他人地址

舍入误差（真实案例 HackerOne #176461）：转账 0.5 satoshi，发送方舍入到 0 不扣款，接收方舍入到 1 多收——无限自动化=无限造币。货币套利：USD 付款 EUR 退款赚汇率差。

## 后台与会员逻辑

- 无订阅访问 premium 端点；购买后取消，检查退款后是否仍可访问（重复退款）
- Burp Match&Replace 翻转 true/false（`isVIP:false→true`）
- 并发数据包突破限购
- 折扣码：多次使用、两账号同时用同一码（竞态）、用于非折扣商品

## 验证码（图形/行为）

- 量化判定：4 位无次数限制 1 万次即破，6 位约 10 分钟；验证码不失效即可撞库
- 检查清单：可机器识别、前端 js 刷新、不过期、本地校验、**删验证码参数提交**
- 滑块/点选：收集全部底图建库对比（极验底图相同仅缺块不同）；机器学习模拟真人轨迹（抖动、匀速区间取随机值）
- 防御：双因子、UA 检测、单 IP 限次、验证码限 3 次错误

## 竞态条件

**所有"限制一次"的功能都测竞态**：超额提现、多次投票、重复兑换礼品卡、绕过邀请限制、绕过 2FA。

### HTTP/1.1 最后字节同步（Turbo Intruder）

```python
engine.queue(request, gate='race1')
engine.queue(request, gate='race1')
engine.openGate('race1')  # 同时释放
```

### HTTP/2 单包攻击（更可靠）

利用 HTTP/2 多路复用一个连接发 20-30 个请求，消除网络抖动。Burp：Repeater → 复制 20 次 → 分组 → Send group (parallel)。

工具：Turbo Intruder、Raceocat、h2spacex。真实案例：礼品卡竞态免费钱、Instagram 密码重置竞态、GitLab CVE-2022-4037。

## 高发注入位提醒

个人信息、地区选择、上传头像处 SQL 注入最多（同位置）；意见反馈/文件上传等提交表单、数值溢出、修改密码 sign 值替换都是入门高频点——**新手从并发逻辑漏洞开始**（每个网站多少都有）。
